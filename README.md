## 📌 Описание

Некоторые серверы (например, **EnvyWorld**) ограничивают работу Plasmo Voice или собственного войс-чата, требуя запуска исключительно через определенный лаунчер (KLauncher) ради рекламы или партнерства. 

Данный мод **подменяет идентификатор лаунчера** в сетевых пакетах при подключении к серверу. Для сервера вы выглядите как игрок с «правильного» лаунчера, благодаря чему голосовой чат разблокируется автоматически. Это позволяет вам играть со своего любимого клиента (Modrinth, Prism, TL Legacy или чистый Vanilla).

## 🚀 Установка

1. Скачайте актуальную версию мода со страницы [Releases](../../releases).
2. Поместите скачанный `.jar` файл в папку `mods` вашего игрового клиента.
3. Убедитесь, что у вас также установлены:
   * Соответствующий загрузчик (Fabric API / Forge)
   * Сам мод на голосовой чат (если требуется клиентская часть)
4. Запустите игру и заходите на EnvyWorld.

## 🛠️ Как это работает (Техническая часть)

Мод перехватывает хендшейк-пакеты (Handshake packets) при авторизации на сервере и внедряет в метаданные строку-маркер, которую сервер ожидает увидеть от KLauncher. Никакие личные данные не модифицируются и не передаются сторонним лицам.

## ⚖️ Дисклеймер

Автор мода не несёт ответственности за возможные блокировки вашего аккаунта на сервере. Использование модификаций, обходящих ограничения сервера, формально может нарушать внутренние правила проекта EnvyWorld. Используйте на свой страх и риск.
